# Калькулятор маршів

Локальний браузерний інструмент для карти «Священні Землі Геліопонту».

## Запуск

Відкрийте `index.html` подвійним кліком. Сервер і встановлення залежностей не потрібні.

Карта також вбудована у `map-data.js`, тому автосканування працює при запуску через `file://` і не залежить від CORS-політики браузера.

## Порядок роботи

1. У вкладці **Налаштування** відкалібруйте шкалу за позначкою «48 миль» на карті.
2. У вкладці **Дороги** натисніть **Просканувати всю карту**. Перегляньте автоматичну чернетку й за потреби додайте пропущені ділянки вручну. Для чистої ручної розмітки проклікайте дороги по їхніх вигинах.
3. У вкладці **Маршрут** виберіть загін, марш і погоду, а тоді клацніть старт та фініш.
4. У вкладці **Позначки** розставте міста, села, форти, важливі місця або власні типи позначок.
5. Експортуйте дані карти в JSON як резервну копію.

Пошук маршруту мінімізує час, а не лише милі. Погода має різні коефіцієнти для дороги й бездоріжжя. Ручний режим бездоріжжя підтримує довільну кількість проміжних точок.

У **Налаштуваннях** можна накласти на карту квадратну або гексагональну координатну сітку. Розмір клітинки задається в милях, а клітинки отримують позначення на зразок `1A`, `2A`, `1B`.

Режим **Висока — агресивна** навмисно зберігає навіть короткі та сумнівні коричневі фрагменти. Зайві ділянки видаляються широкою «Гумкою», яка чистить одразу всю область навколо кліку.

## Редактор доріг

- **Малювати** — створює нову ламану ділянку.
- **Виділення** — клік вибирає дорогу або нод, а протягування по порожньому місцю створює прямокутне групове виділення. `Shift` додає наступну рамку. Вибрану групу, нод або білі точки дороги можна перетягувати; `Delete` видаляє вибране. Перетягування одиночного нода на інший нод об’єднує їх.
- **Швидке продовження** — виберіть один нод і клацніть середньою кнопкою миші. До місця кліку буде прокладено нову ділянку; її кінцевий нод одразу стане вибраним. Клік по іншій дорозі автоматично вставить у неї нод і створить з’єднання.
- **Додати нод** — розділяє наявну дорогу в місці кліку на дві зв’язані ділянки.
- **З’єднати** — клацніть першу і другу дороги; у місцях кліків створяться ноди та нова ділянка між ними.
- **Гумка** — видаляє всі фрагменти в області навколо кліку.

## Позначки

- Є готові типи для фортів, міст, сіл, важливих місць, таборів, портів, храмів, небезпек і армій.
- Для кожної позначки можна вписати назву. Тип і назву можна змінити після встановлення.
- Позначка може зберігати чисельність залишеного гарнізону.
- Час створення записується автоматично. Час останнього спостереження можна поставити кнопкою **Встановити «зараз»** або ввести вручну, якщо армію бачили раніше.
- Для армії можна довільно вказати фракцію, командира та приблизну чисельність — поділу на союзні й ворожі типи немає.
- Для армій відображається, скільки часу минуло після спостереження. За вказаною швидкістю карта також може показувати орієнтовну зону, куди армія могла дістатися.
- Власний тип складається з назви, короткого символу або емодзі та кольору.
- У режимі **Вибирати** позначки можна перетягувати, виділяти прямокутником (із `Shift` для додавання до вибраного) та видаляти клавішею `Delete`.
- Позначки й власні типи зберігаються в `localStorage` та входять до JSON-експорту разом із дорогами, масштабом і сіткою.
